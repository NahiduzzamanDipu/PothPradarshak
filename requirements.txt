# Object Detection and Navigation Assistance for Visually Impaired Individuals
# ---------------------------------------------------------------------------
# Install:
#   python -m venv venv
#   venv\Scripts\activate           (Windows)
#   source venv/bin/activate        (Linux / macOS)
#   pip install -r requirements.txt
#
# GPU NOTE: plain `pip install torch` gives the CPU build on Windows/Linux.
# For an NVIDIA GPU install the CUDA build FIRST, then this file:
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
# Check what you got - this must print True, not just a version:
#   python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
#
# Verified on this project: RTX 3050 Ti Laptop (4 GB), driver 592.00, CUDA 13.1,
# torch 2.11.0+cu128. Auto-labelling went from 0.42 img/s on CPU to 8.26 img/s
# on GPU - a ~20x difference, and training is affected far more than that.
# Pick the cuXXX index matching your driver; cu128 works for CUDA 12.8+.

#   Settings > Time & language > Language & region > Add a language
#   > "বাংলা (বাংলাদেশ)" > tick "Speech"
